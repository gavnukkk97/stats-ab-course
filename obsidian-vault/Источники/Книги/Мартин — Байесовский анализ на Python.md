# Мартин — Байесовский анализ на Python

Освальдо Мартин «Байесовский анализ на Python» (ДМК Пресс, 2020; ориг. Bayesian Analysis with Python, 2nd ed., Packt, 2018). 340 стр. **PyMC3 + ArviZ**.

Чем ценен: единственный в папке практический байесовский учебник с кодом — закрывает «руки» М5. Гл.1–2: байесовский вывод + реализация в PyMC (задача о монете = бета-биномиальная модель конверсий, суммаризация апостериора, ArviZ-диагностика). Гл.1.3 + 5: обобщение апостериора, HDI, апостериорные прогнозирующие проверки, коэффициенты Байеса, WAIC/LOO. Гл.3.4 + 6: иерархическая линейная регрессия и смешанные модели (partial pooling, нецентрированная параметризация) — лучший материал по теме 5.5. Слабости: PyMC3 (не v5 — переносится с минимальными правками), нет бандитов и специализированного байесовского А/В-раздела.

Закрывает: [[Апостериорное распределение]], [[Credible interval]], [[PyMC]], [[Иерархические модели]] (5.5 полностью), [[Байесовский AB-тест]] (практика).

Оригинал: папка «Книги по статистики тер_веру и АБ»; конспект — `Материалы/books-folder.md` §5.

Модуль: [[М5 Байесовские методы]] (5.1–5.3 практика, 5.5).
