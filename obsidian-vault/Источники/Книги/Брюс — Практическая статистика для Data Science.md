# Брюс — Практическая статистика для Data Science

Брюс П., Брюс Э., Гедек П. «Практическая статистика для специалистов Data Science», 2-е изд. (O'Reilly/ДМК, 2021; ориг. 2020). 354 стр., букмарки полные.

Чем ценен: лучший «мост» статистика → Data Science с примерами кода R и Python. Гл.3 — центральная для М2/М3: A/B-тестирование, перестановочные тесты vs t-тесты, p-value/альфа, ошибки I/II, множественное тестирование, ANOVA, мощность и размер выборки, **многорукие бандиты (§3.11 — единственный раздел про бандитов в папке книг → урок 5.4)**. Гл.1–2: EDA, распределения, выборки, бутстрап. Гл.4.5: искажающие переменные (confounders) для М6.
