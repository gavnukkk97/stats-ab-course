# stats_for_science

Телеграм-канал Елены Убогоевой (продуктовый аналитик Литреса, из науки), август 2021 — н.в., ~200 постов. Канал-«курс в постах»: статистика от базы к АБ, много симуляций, историй из биологии/медицины, квизов с разборами.

Чем ценен: лучший канал для М1–М2. Летний ликбез-2026 (~35 постов с домашками) — фактически готовый конспект базового модуля: распределения, ЦПТ ×3 поста, описательные статистики, QQ-plot, все базовые тесты, дерево выбора критерия. Сильный блок про подглядывание/последовательное тестирование, стратификацию, CUPED.

Закрывает: [[ЦПТ]], [[Доверительный интервал]], [[Тест Уэлча]], [[Манн-Уитни]], [[Мощность]], [[FDR]], [[Стратификация]], [[Подглядывание]], [[Последовательное тестирование]], [[CUPED]], [[Base rate fallacy]], [[Описательные статистики]].

Оригинал: дайджест `Материалы/stats_for_science-digest.md` (raw в `materials/telegram/_raw/`).

Модули: [[М1 Базовая статистика]] (лучший из трёх), [[М2 Проверка гипотез]], [[М3 Статистика для АБ]], [[М4 АБ на практике]]; для [[М5 Байесовские методы]] — только тизер.
