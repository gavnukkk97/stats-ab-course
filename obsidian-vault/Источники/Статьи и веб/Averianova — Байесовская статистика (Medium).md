# Averianova — Байесовская статистика (Medium)

Iuliia Averianova, «Байесовская статистика для специалистов по данным» (Medium, Nuances of Programming, 21.01.2021) — вводная статья, один из двух главных источников М5.

Чем ценен: чёткое разделение школ: фреквентисты — параметры фиксированы, данные случайны; байесовцы — параметры случайны, данные фиксированы. [[Теорема Байеса]]: априор × правдоподобие → апостериор; априор кодирует знания до данных (для вероятности на [0,1] естественно [[Априорное распределение|Beta]]); с ростом данных влияние априора тает — противоположные приоры сходятся (демо: Beta(5,2) vs Beta(2,5)); ключевое различие [[Доверительный интервал|confidence interval]] vs [[Credible interval|credible interval]].
