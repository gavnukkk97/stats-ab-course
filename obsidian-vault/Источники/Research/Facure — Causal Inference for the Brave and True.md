# Facure — Causal Inference for the Brave and True

Matheus Facure «Causal Inference for the Brave and True» — бесплатная онлайн-книга, разговорный стиль, **Python** (ноутбуки).

Чем ценен: рекомендованный базовый учебник М6 (research-gaps): потенциальные исходы, DAG, bias, matching, IV, panel data + DiD, Synthetic Control, Double ML, категориальные тритманы, meta-learners (S/T/X-learner), uplift — всё, чего не хватает локальным книгам, с кодом для практикумов. Родственный стек бесплатных книг: Huntington-Klein «The Effect» (theeffectbook.net, аккуратные формальные объяснения fixed effects/DiD/IV/RDD) и Cunningham «The Mixtape» (scunning.com/mixtape.html, социально-ориентированные примеры, Lalonde) — «второй и третий голос» к Facure.

Закрывает: [[Potential outcomes]], [[DAG]], [[Propensity score]], [[Инструментальная переменная]], [[DiD]], [[Synthetic control]], [[Double ML]].

Оригинал: https://matheusfacure.github.io/causal-inference-for-the-brave-and-true/ ; конспект — `Материалы/research-gaps.md` §Задача 4.
