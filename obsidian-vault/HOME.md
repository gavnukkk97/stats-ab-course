# Проверка гипотез: статистика, АБ-тесты, каузальный вывод

Граф знаний (Obsidian-хранилище) по курсу из 6 модулей и всем собранным материалам: локальные курсы и книги, 4 телеграм-канала, веб-статьи и research-обзоры (86+ источников). Построен 2026-09-07; план курса — `course/plan.md` (вне хранилища), карта материалов — [[INDEX]].

## Как открыть в Obsidian
1. Установите Obsidian (obsidian.md).
2. Obsidian → «Open folder as vault» → выберите эту папку `obsidian-vault/`.
3. Разрешите доверие к авторам (Restricted mode можно не отключать — плагины не нужны).
4. Начните отсюда: это HOME; переходите по внутренним ссылкам, граф смотрите через Graph View (Ctrl/Cmd+G).

## Модули курса
1. [[М1 Базовая статистика]] — данные, распределения, ЦПТ, доверительные интервалы, бутстрап
2. [[М2 Проверка гипотез]] — NHST, p-value, ошибки, t-тесты, непараметрика, множественные сравнения, ANOVA
3. [[М3 Статистика для АБ]] — MDE и выборка, юниты, ratio-метрики, CUPED-семейство и ML variance reduction, sequential testing
4. [[М4 АБ на практике]] — OEC и guardrails, сплит-система и SRM, валидность, кумулятивные эффекты и холдауты, экономика, AgentA/B
5. [[М5 Байесовские методы]] — Курт + Мартин (PyMC), байесовский A/B, expected loss, бандиты, иерархические модели
6. [[М6 Каузальный вывод]] — DAG и potential outcomes, квазиэксперименты (DiD, RDD, synthetic control), наблюдательные данные

## Как ориентироваться
- **Учусь по теме**: откройте [[Концепции]] (или поиск по тегу) → у каждой концепции блок «Где почитать» со ссылками на источники и полный текст в [[Материалы]].
- **Ищу источник**: [[Источники]] → заметка источника показывает, какие концепции и модули он закрывает.
- **Двигаюсь по курсу**: [[Курс]] → модуль → урок → концепции.
- **Типы заметок** (frontmatter `type`): `module` — модули, `concept` — концепции, `source` — источники (kind: book/channel/course/article/paper/research), `home` — эта страница. Материалы — исходные конспекты без типа.
- Сквозные принципы курса: «не верь формуле, провери симуляцией» и один сквозной кейс (доставка еды).
