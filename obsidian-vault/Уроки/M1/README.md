# M1. Базовая статистика

Описывать данные, различать распределения и объяснять неопределённость оценки.

Начните с [вводного эксперимента](../../../course/START_HERE.md).

## Как работать с модулем

Тексты уроков лежат в этой папке. В `practice/` находятся готовые исполняемые разборы, в `images/` — все рисунки модуля. В `exercises/` находятся заготовки Python для самостоятельной работы.

Прочитайте урок, попробуйте решить задание до просмотра готового кода, затем запустите разбор и объясните полученный результат. [Как настроить Python](../../../README.md#запустить-первую-практику).
