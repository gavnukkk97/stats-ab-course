# M3. Статистика для А/Б

Планировать размер эксперимента, выбирать единицу анализа и оценивать эффект с учётом особенностей метрики.

Опирается на [M1](../M1/README.md) и [M2](../M2/README.md). Углубления и порядок прохождения указаны в [маршруте](<../../Навигация по курсу.md>).

## Как работать с модулем

Тексты уроков лежат в этой папке. В `practice/` находятся готовые исполняемые разборы, в `images/` — все рисунки модуля. Самостоятельные задания собраны в [общей тетради](../../../course/exercises/README.md).

Прочитайте урок, попробуйте решить задание до просмотра готового кода, затем запустите разбор и объясните полученный результат. [Как настроить Python](../../../README.md#запустить-первую-практику).
