# Иерархические модели

Многоуровневые байесовские модели: параметры сегментов/групп имеют общее гиперраспределение. Partial pooling — сегменты «подтягиваются» к общей средней, крайние оценки сглаживаются.

## Зачем
Оценка по сегментам при малых n: полным pooling размывает различия, отсутствие pooling даёт шумные оценки; частичный pooling — компромисс с автоматической регуляризацией.

## Ключевые идеи
- Практика урока 5.5: иерархическая модель конверсии по регионам на [[PyMC]] (план)
- Байесовский t-тест — ещё один сценарий урока 5.5
- Мостик из Ci2Lab: байесовские сети и факторизация (CH-3, CH-5) — структурный родственный язык
- Empirical Bayes как вычислительно дешёвый вариант частичного пула (связь с [[Априорное распределение]])
- Применение: HTE/CATE по сегментам с честной неопределённостью (см. [[Guardrail-метрики]], [[Стратификация]])
