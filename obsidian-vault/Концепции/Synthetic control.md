# Synthetic control

Синтетический контроль: для одного treated-юнита (регион, город) строится «двойник» — взвешенная смесь контрольных юнитов, подобранная по пре-периоду. Эффект = расхождение после вмешательства.

## Зачем
Оценка эффекта там, где контролей много, но ни один не совпадает: маркетинговые кампании в городах, выкаты в одном регионе. Прозрачен для стейкхолдеров (MCP).

## Ключевые идеи
- Кейс 0 канала shelter: эффективность персональных менеджеров в B2B — контрфактическая модель выручки, синтетический контроль, matching
- Causal Impact (Google): байесовские временные ряды, контрфакт из контрольных серий — родственный метод (MCP)
- Инструменты: scipy/PyMC на симуляциях урока 6.3 (план); CausalML/DoWhy/EconML (koch-kir)
- Стек выбора при SUTVA-нарушениях в АБ: switchback / гео-тесты / synthetic control (abba, кейс маржи)
- Нобелевка-2021 линия: DiD/synthetic control/RDD как инструменты натурных экспериментов (abba_testing)
