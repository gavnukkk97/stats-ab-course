# Априорное распределение

Распределение параметра ДО данных: кодирует знания/убеждения — экспертное суждение или неинформативное. Для вероятности на [0,1] естественно [[Сопряжённость|Beta]].

## Зачем
Априор определяет постериор при малых выборках; с ростом данных его влияние тает — противоположные приоры сходятся к одному постериору (демо: Beta(5,2) vs Beta(2,5) на 100 бросках, Averianova).

## Ключевые идеи
- Спектр приоров: flat / слабоинформативный / empirical Bayes (план 5.1); выбор критичен при малых выборках (Ravichandran)
- Критика байесовства «субъективность приоров» → ответ: слабо-информативные приоры (Ravichandran)
- Практика A/B: априор из base rate реальных эффектов (20%) вместо «все фичи работают» (abba_testing, серия зелёных тестов)
- Чувствительность к априору — обязательная проверка байесовского анализа (план 5.1)
- Empirical Bayes в иерархических моделях — мостик к [[Иерархические модели]]
