# Geo-эксперимент

Рандомизация по гео-единицам (города, регионы): все юзеры региона получают один вариант. Защита от [[Network effects]] и механизм АБ там, где юнит-сплит технически невозможен (офлайн, доставка, реклама).

## Зачем
Когда эффект «перетекает» между юзерами (общий склад, курьеры, офлайн-магазины), сплит по гео изолирует интерференцию внутри кластера.

## Ключевые идеи
- Альтернатива при SUTVA-нарушениях: switchback / гео-тесты / synthetic control — стек выбора из кейса abba (наценка на марже)
- Кластерные (региональные) АБ как базовая защита от интерференции; подбор кластеров по эмбеддингам (shelter, кейс X5)
- Плата: [[Дизайн-эффект ICC]] — мало кластеров → мало df → низкая [[Мощность]]; CUPED по регионам (abba, «региональная специфика»)
- X5 анонсировал geo-дизайны в уроке 5 (слайдов нет); Kohavi гл.22 + план 4.3
- Сочетается с [[Synthetic control]]: контроль строится из взвешенной смеси нетронутых регионов
