# Winner's curse

«Проклятие победителя» — смещение оценки после отбора по её величине или значимости. Даже если исходная оценка несмещённа до отбора, среди отобранных положительных результатов шум в среднем может быть положительным. Поэтому прогноз из выигравших тестов может завышать будущий эффект.

## Ключевые идеи

- Это свойство процедуры отбора и распределения оценок, а не доказательство ложности каждого значимого результата. Даже при одинаковом истинном эффекте наиболее удачная наблюдаемая оценка обычно переоценивает его.
- Type M — связанное понятие: ожидаемый коэффициент преувеличения абсолютной оценки при условии статистической значимости для заданного ненулевого истинного эффекта и дизайна. Универсальной поправки `real_effect = estimate/(TypeM+1)` нет; для неизвестной истины нельзя вычислить Type M одной подстановкой наблюдаемого lift.
- Репликация на независимых данных, заранее спроектированная выборка для валидации, подходящий post-selection inference и иерархический shrinkage помогают при своих условиях. Shrinkage зависит от модели распределения эффектов, её подгонки и учёта неопределённости; это не автоматическое восстановление «истины».
- Оценка decision rule на тех же экспериментах, по которым его выбрали, создаёт дополнительный отбор. Для оценки качества правила используют независимую валидацию или корректную cross-validation.
- При сведении программы экспериментов отдельно учитывают шкалу/композицию маргинальных эффектов, календарную экспозицию и отбор победителей. [[Холдаут-группа]] оценивает заданную пакетную политику с собственной неопределённостью.
