# Стандартная ошибка

Стандартное отклонение выборочной статистики (обычно среднего): SE = σ/√n. Мера шума оценки, а не разброса данных.

## Зачем
Именно SE определяет ширину [[Доверительный интервал|доверительного интервала]] и чувствительность теста: «в 10 раз уже интервал = в 100 раз больше данных» (правило √n, X5 урок 2).

## Ключевые идеи
- σ (разброс данных) vs SE (шум среднего) — классическая путаница с собеседований (stats_for_science)
- Ширина ДИ ∝ σ/√n (stats_for_science, пост про ДИ)
- SE ∝ 1/√n: донабор выборки после «прокраса» даёт лишь квадратичный выигрыш времени (abba_testing, ДИ ч.2)
- Дисперсия → [[Размер выборки]] → длительность теста: цепочка variance reduction ([[CUPED]])
- Для корректного SE при зависимых данных — [[Кластерные SE]]
