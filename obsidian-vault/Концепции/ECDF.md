# ECDF

Эмпирическая функция распределения: доля наблюдений ≤ x для каждого x. Накопительная версия гистограммы, не требует выбора бинов.

## Зачем
Самый честный способ посмотреть форму распределения: не зависит от числа бинов (в отличие от гистограммы), показывает квантили и хвосты; основа критерия Колмогорова–Смирнова.

## Ключевые идеи
- План урока 1.2: ECDF и боксплоты alongside гистограмм с правилами Стерджесса/Скотта/ФД (koch-kir)
- В Симуляторе (урок 4) кумулятивные гистограммы p-value — та же идея для проверки теста: A/A → равномерная ECDF
- Spanos (гл.5) — t-plots и эмпирическая CDF как инструменты чтения реальных данных
- Перцентильный анализ распределения эффекта по децилям — «локализация эффекта» (Atlamos, бутстрап; план урока 4.4)
