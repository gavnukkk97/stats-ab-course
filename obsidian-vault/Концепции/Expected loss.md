# Expected loss

Для выбора B при метрике «больше лучше»: EL_B=E[max(A−B,0)|D]. EL_A=E[max(B−A,0)|D]. Это среднее по всему posterior, включая нулевой ущерб при правильном выборе, а не E[потеря|выбор ошибочен].

Стоп при EL выбранной версии < ε ограничивает её модельную апостериорную потерю. При корректной модели можно получить prior-predictive байесовский риск, но не равномерную frequentist-гарантию для каждого истинного эффекта и произвольного prior. Проверяйте чувствительность к prior, повторными симуляциями — конкретную политику, и отдельно guardrails.

При равных наблюдаемых конверсиях p и n на руку нормальная аппроксимация даёт EL≈√(p(1−p)/(πn)); значит n≈p(1−p)/(πε²). При p=.1 и ε=.001 это около 28 648 на руку.
