# Дизайн-эффект ICC

Design effect = 1 + (m−1)·ICC: во сколько раз вырастает дисперсия оценки при кластеризации, для равных размеров кластеров m (подстановка среднего при неравных размерах лишь приближение), ICC — внутрикластерная корреляция. Эффективный n событий = n / design effect. Если дисперсия уже рассчитана по пользовательским/кластерным агрегатам, повторно умножать её на DEFF нельзя.

## Зачем
Кластерные дизайны (магазин, регион, гео) лечат интерференцию, но «вводят ICC»: без design effect [[Размер выборки|размер выборки]] и [[Мощность|мощность]] посчитаны наивно — тест недомощен (koch-kir; abba).

## Ключевые идеи
- Формула из koch-kir «Кластерные эксперименты»: effective n падает; MDE/power считать на юните анализа с учётом кластеризации
- abba (офлайн-ритейл): чем опасен сплит по чекам (кластеры магазинов игнорировать нельзя), мощность через df кластеров; switchback по неделям как вариант
- Кластерные эксперименты как «базовая защита от интерференции» — региональные АБ (shelter, рубрика сетевых эффектов)
- Выбор кластеров: word2vec/doc2vec-эмбеддинги item_id и клиентов для подбора однородных кластеров (кейс X5, shelter)
