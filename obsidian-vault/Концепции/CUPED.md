# CUPED

Controlled-experiment Using Pre-Experiment Data — снижение дисперсии метрики: Y_cuped = Y − θ(X − E[X]), где X — ковариата из pre-period, θ = cov(Y,X)/var(X). Вычитаем предсказуемую часть — остаётся шум меньше.

## Зачем
Цепочка: меньше дисперсия → меньше [[Размер выборки|выборка]] → быстрее тест → больше тестов за квартал (X5 урок 4). Выигрыш по дисперсии ≈ ρ², множитель чувствительности 1/(1−ρ²) (Deng гл.10; stats_for_science).

## Ключевые идеи
- Идейный предок — diff-подход/[[Парный t-тест]] (Симулятор 9): повторяющееся поведение юзера, метрика-разность снижает дисперсию в разы
- CUPED = линейная регрессия = ANCOVA; 4 строчки кода до MultiCUPED (shelter «CUPED под микроскопом» гл.3–4; abba «Что было бы, если бы CUPED не изобрели»)
- Выбор пре-периода и способ оценки θ: три сценария (по всем данным / pooled / по группам — практики Booking/Walmart vs Netflix/Airbnb vs Meta/Microsoft), DBF vs MBF симуляции (shelter; abba «Точки над CUPED»)
- Цифры X5: дисперсия −42%, выборка 570→330 на группу; CUPAC (ML-прогноз по 40 фичам) — до −61%, но требует ML-инфры; не сработает для новых юзеров без истории
- CUPED для [[Ratio-метрика|ratio]] — обобщение [[Стратификация|стратификации]] + пост-нормировка против перекосов сплита (shelter гл.5–7)
- Риск: смещение при нарушении инвариантности ковариаты ([[stats_for_science]]: ковариата пре-периода, риск при нарушении инвариантности)
