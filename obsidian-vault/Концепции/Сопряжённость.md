# Сопряжённость

Априор и правдоподобие подобраны так, что апостериор имеет то же семейство, что и априор: Beta-априор + бернуллиевские данные → Beta-апостериор. Обновление сводится к сложению счётчиков.

## Зачем
Позволяет считать [[Байесовский AB-тест|байесовский A/B]] на конверсиях аналитически, «с нуля без MCMC» (план 5.3) — основа практикума урока 5.1.

## Ключевые идеи
- Числовой пример Ravichandran: Beta(5,95) + 3 успеха/17 неудач → Beta(8,112); последовательные обновления сужают интервал
- Монета из урока 5.1: последовательное обновление Beta-апостериора, сходимость при разных приорах
- Параметры апостериора: α' = α + успехи, β' = β + неудачи — мгновенное обновление по мере прихода данных
- Сопряжённые пары для других likelihood (Пуассон–гамма, нормальный–нормальный) — стандартный справочный материал
