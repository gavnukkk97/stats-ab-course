# Интерференция экспериментов

Взаимовлияние параллельных тестов при пересечении аудиторий: эффекты взаимодействуют, рандомизация не гарантирует равность условий ([[koch-kir — Влияние экспериментов]]).

## Зачем
На платформе десятки параллельных тестов; непонятые взаимодействия искажают оценки обоих тестов — а «Buoyancy/тасование» (пересекающиеся аудитории как ковариаты) может даже помогать, если понимать механику.

## Ключевые идеи
- Механика: конкуренция за слот на странице, комбинированный вариант (koch-kir)
- Важна ВЕЛИЧИНА пересечения, а не факт: 0.1% при низкой конверсии пренебрежимо (koch-kir)
- Сначала проверяй [[SRM]] — возможно, сломано расписание экспериментов; при случайном пересечении — таблица 2×2 для оценки взаимодействия (koch-kir)
- Ортогональные схемы (2⁶=64 комбинации) нереальны; альтернативы — последовательный запуск или слои/непересекающиеся аудитории (koch-kir; [[Сплит-система]])
- Deng гл.9: детекция взаимодействий между экспериментами; abba: Buoyancy/тасование тестов, ковариаты других тестов с симуляциями
- Симулятор 11: коррелированные группы — одна группа не может быть контролем в двух тестах
