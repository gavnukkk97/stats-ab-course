# Пост-стратификация

Стратификация «после факта»: группы уже получены случайным назначением, а на анализе оценка взвешивается по стратам (взвешенное среднее стратовых средних). Спасение, когда дизайн не позволил стратифицировать заранее.

## Зачем
Дисбаланс долей страт между группами всё равно случается даже при честной рандомизации; взвешивание убирает between-strata компоненту дисперсии — выигрыш почти как у дизайн-[[Стратификация|стратификации]] (X5 урок 4).

## Ключевые идеи
- Три подхода Симулятора (урок 8): классика / стратификация (дизайн) / пост-стратификация (анализ) — сравнить на одном датасете
- Оценщик: взвешенное по долям страт среднее; Var = Σ W_h²·S_h²/n_h (research-sensitivity, план блока «чувствительность»)
- На практике [[CUPED]] часто превосходит стратификацию/пост-стратификацию: непрерывная ковариата вместо грубых страт (Larsen et al. 2023, обзор — «правило большого пальца»)
- Сравнение stratification / post-stratification / CUPED — HKU L6 (кейс Netflix real-time stratified sampling)
- Жадный выбор стратификационных переменных (Momozu et al., PRICAI 2025); дизайн-альтернатива COSS — сортировка по ковариате + чередующееся назначение (arXiv 2404.10381)
