# Мета-анализ экспериментов

Объединение результатов множества экспериментов платформы: распределение истинных эффектов, институциональная память, совокупные выводы вместо одного теста. Kohavi гл.8 «Institutional Memory and Meta-Analysis»; метод Фишера объединения p-value (HKU L3).

## Зачем
Один A/B отвечает на один вопрос о фиче; платформе нужно понимать корпус экспериментов: какая доля идей работает, как распределены эффекты, чему учитывается velocity и планирование.

## Ключевые идеи
- Kohavi KDD 2013: только ~⅓ идей в Bing улучшают целевые метрики (200+ параллельных тестов) — стартовая статистика для курса и планов
- Georgiev «What Can Be Learned From 1001 A/B Tests?»: распределения эффектов и power «в дикой природе» — эмпирика для калибровки [[MDE]] и приоров
- Fisher's method объединения p-value (HKU L3); «мощность без синиц» и power analysis (stats_for_science)
- Мета-анализ «наоборот»: батчить запущенные тесты и сверять сумму предсказанных эффектов с [[Холдаут-группа|холдаутом]] (рекомендация Kohavi)
- Netflix: правила «катить/не катить» оценивают на корпусе своих же тестов (many weak experiments) — кросс-валидация decision rules (+33% north star; trisigma)
