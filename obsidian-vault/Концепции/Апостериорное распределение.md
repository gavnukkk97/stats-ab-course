# Апостериорное распределение

Распределение параметра ПОСЛЕ данных: смешивает информацию данных и априора. Полное байесовское «решение» — из него достают точки, интервалы и вероятности.

## Зачем
Вместо одной точки (частотная оценка) — распределение уверенности: напрямую отвечает на вопросы вида «какова вероятность, что B лучше A».

## Ключевые идеи
- Постериор ∝ правдоподобие × априор; итеративное обновление порциями данных (Ravichandran)
- Из постериора: [[Credible interval]], P(B>A), [[Expected loss]] — всё для [[Байесовский AB-тест|байесовского A/B]]
- С ростом данных постериор практически не зависит от априора (сходимость Beta(5,2) и Beta(2,5)) (Averianova)
- Bayes Factor K = постериорные шансы / априорные шансы — сравнение моделей; шкала Kass & Raftery (abba_testing, цикл mSPRT ч.1)
- Для сложных моделей постериор считается MCMC ([[PyMC]]); для [[Сопряжённость|сопряжённых]] — аналитически
