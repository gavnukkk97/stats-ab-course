# Ratio-метрика

Метрика-отношение сумм: средний чек = Σвыручка/Σчеков, CTR = Σклики/Σпоказы. Числитель и знаменатель зависимы, юнит изменения (заказ) мельче юнита анализа (юзер).

## Зачем
Один агрегированный ratio на руку не даёт выборки для обычного t-теста. Тест по событиям ошибается, если игнорирует зависимость внутри пользователя. «Среднее средних» — не сонаправлено с ratio, риск неверного решения (Симулятор 12).

## Ключевые идеи
- Три корректных способа: [[Бутстрап]] по юзерам (семплировать числитель+знаменатель целиком), [[Дельта-метод]], [[Линеаризация]] (Симулятор 12; Atlamos)
- Дисперсия ratio и «variance lift» — отдельная тема (HKU L5 variance_lift.ipynb)
- Kohavi гл.18: delta vs delta%, ratio-метрики, выбросы, чувствительность
- X5 урок 4: AOV = выручка/заказы — анализ учитывает зависимость заказов одного пользователя
- [[CUPED]] на ratio-метриках — через линеаризацию или совместный дельта-метод (shelter, «CUPED» гл.5–7)
