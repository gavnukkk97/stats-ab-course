# Тест Уэлча

Вариант [[t-тест]]а для средних независимых групп без предположения равных дисперсий. Разумный дефолт, но зависимость и тяжёлые хвосты при малом n остаются ограничениями. С pooled-тестом полностью совпадает при равных n и выборочных дисперсиях; равенства только σ недостаточно для одинаковых df.

## Зачем
У Стьюдента при неравных дисперсиях и n уровень может быть завышен или занижен в зависимости от того, где больше дисперсия и размер группы. При равных n совпадают SE, но pooled-df всё ещё требуют обоснования.

## Ключевые идеи
- Симуляционное сравнение Стьюдента и Велча на ubogoeva.github.io (R4Analytics): вывод «Велч по умолчанию» (stats_for_science, дважды: октябрь 2024 + рецензия статьи X5 январь 2026)
- Реальная α превышает номинальную, если использовать Стьюдент вместо Велча при неодинаковых дисперсиях (stats_for_science, перечисление причин)
- Дельта-метод для ratio-метрик восходит к методу Уэлча 1949 (koch-kir)
- Курс: Велч упоминается в правиле выбора t vs z (HKU L2)
