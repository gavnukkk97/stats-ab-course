# Линеаризация

Перевод [[Ratio-метрика|ratio-метрики]] на пользовательский уровень: сигнал юзера = числитель_юзера − ratio_контроля × знаменатель_юзера. Матожидание в контроле = 0; разница линеаризованных метрик сонаправлена изменению ratio (Atlamos).

## Зачем
Открывает для ratio-метрик весь арсенал поюзерных методов: [[CUPED]], [[Стратификация]], [[Кластерные SE]] — чего не даёт [[Дельта-метод]]. Связка «линеаризация + CUPED» внедрена в платформу Купера.

## Ключевые идеи
- p-value линеаризации консистентны дельта-методу (Atlamos; Симулятор 12)
- В финальном проекте Симулятора (урок 13) оценка значимости «ускорения доставки» делается линеаризацией
- Порядок: ratio_контроля считается по контрольной группе; метрика центрируется
- Линеаризация + variance reduction для ratio — стандартный прод-пайплайн (Симулятор 12; shelter «CUPED» гл.5–7)
