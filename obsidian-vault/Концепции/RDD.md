# RDD

Regression discontinuity использует разрыв вероятности лечения в известном пороге running variable. В sharp RDD при непрерывности E[Y(0)|X=x] и E[Y(1)|X=x] в пороге разрыв исхода идентифицирует локальный эффект.

Порог не создаёт рандомизацию автоматически. Нужны отсутствие иных скачков в том же пороге и обоснование отсутствия сортировки, нарушающей непрерывность. Проверки плотности и pre-ковариат помогают выявить проблемы, но не доказывают допущение. Для дискретного score с малым числом значений требуется дополнительная модель или иной inference.

Fuzzy RDD при неполном соблюдении порога использует отношение скачков исхода и лечения; при соответствующих IV-допущениях это локальный LATE. Bandwidth, спецификация и корректный CI влияют на результат. Практика [practice_6_3.py](../../course/modules/M6/practice/practice_6_3.py) обсуждает дизайн, без полноценного RDD-пакета.
