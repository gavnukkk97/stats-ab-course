# Кластерные SE

Стандартные ошибки, скорректированные на кластеризацию наблюдений (юзер → несколько заказов, магазин → много чеков): внутри кластера наблюдения коррелированы, и обычные SE занижены.

## Зачем
Без кластерных SE реальная [[Ошибка I рода|ошибка I рода]] взлетает: «гигантская выборка не спасает» — кластеризация и смещение не убывают с n (stats_for_science).

## Ключевые идеи
- «Что если данные не случайны»: автокорреляция → кластерные SE, блоковый бутстрап (stats_for_science)
- Практика: statsmodels регрессия с cluster-SE (HKU L5 cluster.ipynb)
- abba: сплитование по магазинам в офлайн-ритейле — кластерные тесты, мощность через df кластеров
- Связка с design effect: кластеризация = эффективная выборка меньше ([[Дизайн-эффект ICC]])
- Причины кластеризации: юнит анализа мельче юнита рандомизации ([[Юнит рандомизации]]; koch-kir)

Связано: [[Дизайн-эффект ICC]], [[Юнит рандомизации]], [[Стандартная ошибка]], [[Network effects]]
