# Switchback-дизайн

Дизайн с переключением: одна и та же единица (магазин, город, курьерская зона) попеременно получает то контроль, то тритмент по расписанию (например, по неделям или дням).

## Зачем
Лечит интерференцию/[[Network effects]], когда юнит-уровневая рандомизация невозможна (общий склад, офлайн-ритейл): усреднение по времени вместо параллельных групп.

## Ключевые идеи
- abba: кейс наценки на марже — при нарушении SUTVA через общий склад переход на switchback / гео-тесты / synthetic control
- Офлайн-ритейл: сплитование по магазинам, switchback по неделям; мощность через df кластеров, [[Дизайн-эффект ICC]] (abba)
- koch-kir: кластерные дизайны (кластерная рандомизация, switchback) лечат интерференцию, но вводят ICC
- X5 анонсировал урок 5 «продвинутые дизайны (switchback/geo)» — слайдов пока нет; база — Kohavi гл.22 (план, пробел 3)
- Требование: стационарность/отсутствие сильной сезонности внутри окна; учёт carryover-эффектов
