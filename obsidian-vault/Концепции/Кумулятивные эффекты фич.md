# Кумулятивные эффекты фич

Последовательная раскатка: каждая фича протестирована против «нет фичи», вместе — никогда. Эффекты неаддитивны: взаимодействие, каннибализация, обучение пользователей, перегрузка UI — «сумма зелёных может быть красной».

## Зачем
Лонгрид Trisigma «Кто съел мой прирост?»: почему сумма эффектов выигранных тестов ≠ фактический прирост метрики. Без понимания кумулятивных эффектов планирование и отчётность врут.

## Ключевые идеи
- Eppo «The Whole Is Less Than the Sum of Its Parts»: при последовательной раскатке целое < суммы — прямой текст про неаддитивность
- «Why is my A/B test flat?» (перевод, trisigma): пики/впадины, липкость (stickiness), кумулятивный эффект фич; кейс редизайна тулбара Gmail
- Кейс X5/abba: CVM-коммуникации действуют с лагами, перенос эффекта во времени, каннибализация между кампаниями — модель кумулятивных каннибализаций официально используется (адаптируют Ozon)
- Проверка суммарного эффекта — [[Холдаут-группа]] (global/long-term holdout);_correlating с [[Winner's curse]] для смещения отбора
- Кейс «тест на марже» (abba): каннибализация через общий склад = нарушение [[SUTVA]] → switchback/гео-тесты/synthetic control
