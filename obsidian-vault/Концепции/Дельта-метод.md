# Дельта-метод

Асимптотический метод расчёта дисперсии функции случайных величин через разложение Тейлора: SE(g(X)) ≈ g'(μ)·SE(X). Для [[Ratio-метрика|ratio]] — метод Уэлча 1949.

## Зачем
Даёт аналитическую дисперсию (и p-value) для ratio-метрик без бутстрапа: быстро, масштабируется на сотни метрик — поэтому в проде автор shelter «официально отказался от бутстрапа».

## Ключевые идеи
- Совпадает с бутстрапом по p-value (Atlamos; Симулятор 12), но не даёт поюзерных сигналов — нет [[CUPED]]/[[Стратификация|стратификации]] сверху
- При n>100 в группах дельта-метод ≈ линеаризация по результатам (koch-kir, симуляции)
- Общая рамка: M- и Z-оценщики, асимптотическая нормальность (Deng гл.11)
- Связь с ЦПТ: асимптотическая нормальность ratio-оценщика — следствие [[ЦПТ]] + дельта-метод
- Регрессионная форма: рег-тесты для ratio и квантильных оценок (shelter, дельта-метод ч.2)
