# Бутстрап

Метод ресэмплинга: многократные случайные подвыборки с возвращением из исходной выборки (1000–10000 итераций) строят эмпирическое распределение любой статистики.

## Зачем
[[Доверительный интервал]] для медианы, перцентилей, [[Ratio-метрика|ratio-метрик]] — там, где формулы неудобны. «Швейцарский нож аналитика» (Atlamos) — но не волшебный.

## Ключевые идеи
- Не создаёт информации и не повышает репрезентативность — только вариативность (Atlamos, бутстрап)
- Бут-выборки строго в объёме исходной выборки, иначе искажается дисперсия (Atlamos)
- На средних — «затратная аппроксимация t-теста» (~80% мощности в примере Atlamos); не масштабируется на сотни метрик — поэтому в проде [[Дельта-метод]] (shelter_analytics)
- Для ratio семплировать юзеров целиком (числитель+знаменатель вместе); для зависимых данных — стратифицированный/кластерный бутстрап (Atlamos; abba_testing, «Кнопка: бутстрап»)
- Johnston & Faulkner 2020: Манн-Уитни даёт до 17% ложных срабатываний на ненормальных данных — бутстрап надёжнее (stats_for_science)
