# Доверительный интервал

Интервал, построенный по выборке, который при повторении экспериментов накрывает истинное значение параметра в заданной доле случаев (например, 95 из 100).

## Зачем
Переводит «значим/незначим» в язык величины эффекта: сообщать эффект с ДИ правильнее, чем один p-value (shelter: «решения — по размеру эффекта, ДИ и дизайну, а не по p-value»).

## Ключевые идеи
- Частотная интерпретация: «95 из 100 экспериментов», а НЕ «95% вероятность, что параметр внутри» — это уже [[Credible interval]] (stats_for_science; Averianova)
- Виды CI: нормальный / перцентильный / центральный — различие заметно на несимметричных распределениях (Симулятор, урок 5)
- Проверка гипотез через CI: ноль вне интервала ↔ значимость (Симулятор, урок 5)
- Правильная интерпретация при мощности 80%: покрытие значимыми 95% ДИ ≈ 77.5%, а не наивные 76% (abba_testing, симуляции)
- CI для произвольных статистик — через [[Бутстрап]]; ширина ∝ σ/√n ([[Стандартная ошибка]])
