# OEC

Overall Evaluation Criterion — одна главная метрика теста, по которой принимается решение. «Число, по которому готовы принять решение», а не просто число (X5 урок 4).

## Зачем
Без единого OEC решение размывается по десяткам метрик → [[Множественные сравнения]] и p-hacking; «один OEC» — противоядие X5 (кейс: 18 метрик → нужен p<0.0028).

## Ключевые идеи
- Гипотеза X→Y→Z и иерархия метрик: целевая ≈ деньги (выручка), специфичность vs каннибализация (сок ↔ весь ассортимент) (Симулятор 7)
- Свойства хорошей метрики: чувствительность, стабильность, интерпретируемость — «выбери 2 из 3» (X5 урок 4)
- Кейс X5: CTR — слабый, конверсия в заказ — хороший OEC, LTV 90d — только в guardrails через прокси retention 7d
- Прокси-метрики: валидный прокси (retention 7d ↔ LTV, корреляция 0.8) vs сломанный (time-on-page); закон Гудхарта (X5; stats_for_science)
- OEC-примеры индустрии: Amazon e-mail, Bing (Kohavi гл.7)
