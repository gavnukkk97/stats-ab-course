# ML variance reduction

Снижение дисперсии через прогноз метрики: [[CUPAC]], регрессионная поправка, другие design-aware оценщики. Формула Var_adj=Var_raw(1−R²) относится к конкретной оптимальной проекции, не ко всем ML-оценщикам или in-sample R².

Для Lin нужны центрирование, взаимодействия T×X, робастные SE и обычные асимптотические условия при фиксированной размерности и ненулевых долях групп. Обычная аддитивная OLS при рандомизации также состоятельна, но без взаимодействий может проиграть по эффективности при неравном сплите. Гарантии «не ухудшить» не конечновыборочные.

Для гибкого ML используйте независимое обучение/OOF-прогнозы и подходящую inferential-конструкцию; одних пре-признаков недостаточно. Множитель трафика измеряйте по дисперсии оценки конкретной метрики; не переносите на календарные дни без условий. Связано: [[CUPED]], [[CUPAC]], [[Double ML]].
