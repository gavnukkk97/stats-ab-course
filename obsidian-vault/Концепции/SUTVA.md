# SUTVA

Stable Unit Treatment Value Assumption: (1) исход юнита не зависит от назначений другим юнитам (нет интерференции) и (2) одна версия лечения (нет скрытых вариантов). Базовое допущение честного A/B.

## Зачем
Без SUTVA разница групп ≠ эффект: эффект «утекает» между группами. Кейсы распознаются по механике: общий склад, маркетплейс, P2P.

## Ключевые идеи
- Кейс abba: тест наценки на марже — контроль и тест делят общий склад, продажи каннибализуются → SUTVA нарушен → [[Switchback-дизайн]]/[[Geo-эксперимент]]/[[Synthetic control]]
- Нарушения SUTVA в экспериментах — серия слайдов HKU L4; сетевые интерференции ([[Network effects]])
- Что делать при интерференции: кластерная/региональная рандомизация, изоляция вариантов (Kohavi гл.22; shelter «правила дизайна эксперимента»)
- SUTVA в каузальной рамке: часть условий идентификации [[Potential outcomes|potential outcomes]] (Deng гл.4)
- Вторая часть (одна версия): «две версии одной кнопки = два разных тритмента» — почему деградации и частичные выкатки ломают анализ
