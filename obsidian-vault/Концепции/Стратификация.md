# Стратификация

Баланс групп по стратам (гео, пол, платформа, формат магазина): стратифицированное семплирование на дизайне + стратифицированное среднее на анализе; пост-стратификация — спасение взвешиванием после факта.

## Зачем
Простое случайное семплирование даёт дисбаланс долей страт между группами → лишний шум. Стратификация −67% разброса оценки (X5 урок 4); выравнивает ковариаты при малых n (stats_for_science).

## Ключевые идеи
- Три подхода Симулятора (урок 8): классика / стратификация / пост-стратификация; нули в выручке — не выбросы
- Стратификация (до) vs сегментация (после): «сегменты, заявленные до теста — анализ; найденные после — HARKing» + [[Множественные сравнения]] (X5)
- Кейс Netflix: real-time stratified sampling (HKU L6); сравнение stratification / post-strat / CUPED
- CUPED как обобщение стратификации (shelter «CUPED» гл.5–7); выбор числа страт и когда не помогает (stats_for_science, серия ×4)
- Кейс X5: стратификация по формату магазина (Пятёрочка 74% / Перекрёсток 16% / Чижик 10%)
