## Правила ведения

- **Одна лекция — одна папка.** Название: `Лекция NN — короткое название`.
- **Финальная дека Commit'ится сразу после лекции** (или до): тот файл, что
  показывался студентам, без суффиксов «копия/final».
- **Рукописные пометки с проектора не коммитим.** Если PowerPoint сохранил
  ink-пометки поверх слайдов (рисование ручкой во время показа) — сначала
  очистить (см. заметку ниже), потом заливать. Рабочие копии с пометками
  остаются на рабочем столе, в git — чистовый вариант.
- PDF-версии и черновики не храним — только исходники `.pptx`.
- После каждой лекции обновлять таблицу выше (дата + статус).

## Заметка: как чистить ink-пометки в pptx

PowerPoint при рисовании ручкой во время показа сохраняет штрихи как
`p:contentPart` (InkML) + PNG-заглушку. Удаление через XML:
вырезать блоки `<mc:AlternateContent>…<p:contentPart>…</mc:AlternateContent>`
из XML слайдов, убрать соответствующие записи из `_rels` слайда, файлы
`ppt/ink/*.xml`, fallback-картинки и их `Override` в `[Content_Types].xml`.
Скрипт-пример: см. историю коммита с сообщением «очищена от ink-пометок»
(лекция ВШЭ 01, слайды 9, 10, 13–16, 18–23, 25, 33, 35).
