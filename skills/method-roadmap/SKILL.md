# Дорожная карта: как на практике выбирают метод

![Как на практике выбирают метод](assets/decision_roadmap.png)

## Практическая правда (что происходит в реальной работе)

1. **Сначала борись за эксперимент.** Рандомизация — единственный метод, который уравнивает группы по всему, включая ненаблюдаемое. 90% продуктовых вопросов закрываются A/B-тестом (М3–М4). Сеть мешает → geo/switchback; дорого ждать → sequential.
2. **Нельзя рандомизировать** (этика / дорого / уже произошло / эффект на всех) → иди по лестнице вниз, каждое допущение проверяй:
   - есть контрольная группа и данные до → **DiD** (проверь параллельные тренды!) → PSM+DiD / DR-DiD
   - решение по порогу → **RDD** (74 vs 76 — «почти близнецы»)
   - один юнит → **synthetic control / ITS**
   - только ковариаты → **PSM/IPW/DR** (баланс, плацебо)
   - есть внешний толчок → **IV**
3. **Ничего нет → не делай выводов.** Слабый дизайн + давление бизнеса = самое опасное. Скажи: «можем дать оценку при допущениях, не доказательство».

## Правила практики
- Каждый шаг вниз по лестнице = новые допущения → плацебо-тесты и sensitivity всегда
- «Не отвергли H0» ≠ «эффекта нет» (мощность!); «значимо» ≠ «важно» (CI + деньги!)
- Сомневаешься — вернись на шаг вверх: может, эксперимент всё же возможен
