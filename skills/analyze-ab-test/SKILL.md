# Анализ A/B-теста: пайплайн от логов до вердикта

## Порядок (не менять!)

1. **Валидация данных**: SRM (χ² по долям групп, порог p<0.001 — сломано → чинить и перезапускать, результатам не верить); инварианты на месте; exposure ≠ лог-тайм
2. **OEC**: эффект + 95% CI + p (Уэлч; ratio → дельта-метод/линеаризация). Не «прокрасилось/нет», а размер + неопределённость
3. **Чувствительность**: если планировался CUPED — применить (θ на pooled, ковариата ТОЛЬКО пре-период); CI сжимается в 1/√(1−ρ²)
4. **Guardrails**: каждый проверен; просел значимо → стоп независимо от OEC
5. **Secondary-метрики**: только с поправкой (Холм) — информационные, не решающие
6. **Локализация**: децильный анализ по ПРЕ-метрике — где эффект (тело или хвост; вспомни винзоризацию)
7. **Сегменты**: только заявленные заранее + поправка; нарезка «до победителя» = техасский снайпер (winner's curse)
8. **Вердикт по decision rule** (из дизайн-дока) + отчёт: эффект, CI, guardrails, рекомендация roll/hold/iterate

## Интерпретация
- p-value при верной H0 равномерен — «p=3.6e-27» не добавляет уверенности
- Согласованность метрик (клики→конверсия→деньги) сильнее одного числа
- Статзначимость ≠ практическая: перевод эффекта в ₽/дни/юнит-экономику
- Кумулятивные эффекты: сумма «зелёных» релизов ≠ прирост (winner's curse + взаимодействия) → сверяйся с холдаутом

## Грабли
- Peeking: если смотрели ежедневно без sequential — α уже 25%+, вывод невалиден
- Эффект в хвосте + винзоризация = эффект «исчез» (проверь децили до винзоризации)
- Segment without correction = найдёшь «победителя» в шуме
