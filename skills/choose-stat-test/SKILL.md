# Выбор статистического теста

## Сначала вопрос и дизайн

1. Зафиксируйте **estimand**: средняя выручка на назначенного пользователя, разность конверсий, квантиль, AUC или ratio. Скошенность не даёт права заменить ARPU медианой, рангами или средним log-выручки.
2. Установите единицу назначения и зависимости. Несколько заказов одного пользователя — кластер: агрегируйте по пользователю либо учитывайте кластеры в SE/ресэмплинге. Парный анализ допустим для настоящих пар; выигрыш зависит от корреляции. До/после одной группы не идентифицирует причинный эффект.
3. Задайте H0, направление, семейство гипотез и правило решения **до данных**. Для запрета хотя бы одного ложного открытия — FWER (например, Холм). Для ожидаемой доли ложных среди разведочных находок — FDR (BH при независимости/PRDS, BY при произвольной зависимости). Число тестов не выбирает нужную гарантию за вас.
4. Повторные взгляды требуют отдельного плана: фиксированный горизонт, заранее K взглядов с α/K или обоснованная sequential-процедура. Нельзя выбирать число взглядов и направление после результата.

## Методы и условия

| Вопрос | Возможный метод | Что проверить |
|---|---|---|
| Разность двух конверсий | z-тест долей / χ² | независимые единицы, ожидаемые успехи и неуспехи в каждой группе достаточно велики (ориентир ≥10); при редких событиях — точный Fisher или обоснованный маловыборочный метод |
| CI одной доли / разности долей | Wilson / Newcombe или score-CI для разности | два отдельных Wilson-CI не являются CI разности; согласовать тест и интервал |
| Разность поюзерных средних | Welch t | независимость, конечная дисперсия и достаточная калибровка студентизированной разности; правило 100·skew² лишь эвристика |
| Среднее при малом n и тяжёлом хвосте | увеличить данные; оценить калибровку Welch/студентизированной перестановки | обычная перестановка разности средних точна при обменяемости/строгой randomization-H0, не при произвольном равенстве средних; bootstrap не восстанавливает невидимый хвост |
| Одинаковые распределения; ранговое различие | Mann–Whitney | H0 одинаковых распределений; U/(mn) оценивает P(X>Y)+0,5P(X=Y); это не универсальный тест слабой H0 AUC=0,5 и не тест ARPU/медиан |
| Слабая H0 AUC=0,5 при разных формах | Brunner–Munzel / обоснованная студентизация | независимость, маловыборочная калибровка, ties |
| Медиана/перцентиль | bootstrap-CI или специализированный квантильный метод | достаточность наблюдений около квантили, состоятельность статистики, покрытие percentile/basic/BCa |
| Киты | анализ хвоста и CI выбранной метрики | винзоризация с заранее общим порогом меняет estimand; сообщить денежный эффект отдельно |
| Средние 3+ независимых групп | классическая ANOVA при равных дисперсиях; Welch ANOVA иначе | распределение ошибок, размеры групп; заранее выбранные сравнения и поправка на семейство. Alexander–Govern — другой тест |
| Ratio (AOV, CTR) | дельта-метод / линеаризация / bootstrap юнитами | числитель и знаменатель ресэмплировать вместе, единица анализа соответствует назначению; см. М3.3 |

## Отчёт

Покажите оценку эффекта, CI, n и единицы, p/скорректированный p, проверенные допущения и бизнес-порог. p=0,049 и 0,051 дают близкую силу свидетельств; прохождение порога не доказывает полезность. Для малого n допустимый вывод — «данных недостаточно». Проверки калибровки сопровождать Monte Carlo CI; для разных estimand нельзя выбирать «самый значимый» тест.
