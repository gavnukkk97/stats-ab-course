# Выбор статистического теста

## Алгоритм в три вопроса

1. **Что за метрика?**
   - доля (конверсия, retention) → z-тест долей / χ² (для n≥… достаточно нормальной аппроксимации)
   - поюзерное среднее (ARPU, клики/юзер) → t-тест **Уэлча** (`equal_var=False` — всегда дефолт)
   - ratio-метрика (средний чек = Σвыручка/Σзаказы, CTR) → дельта-метод / линеаризация / бутстрап **юзерами** (см. `../../course/content/M3/lesson-3.3.md`)
   - медиана/перцентиль/сложная статистика → бутстрап или permutation
2. **Как устроены наблюдения?**
   - независимые группы → двухвыборочные тесты
   - до/после на тех же юзерах → **парный** t (SD разностей меньше — бесплатная мощность)
   - юнит анализа мельче юнита рандомизации (заказы внутри юзера) → кластерные SE или агрегируй до юзера
3. **Сколько тестов?** больше одного (несколько метрик/сегментов/заглядываний) → поправка: 3–5 гипотез → Холм; десятки → BH (FDR). FWER без поправки при 20 метриках = 64%.

## Шпаргалка-таблица

| Ситуация | Тест | Не забыть |
|---|---|---|
| конверсия A vs B | z-тест долей | Wilson-CI при редких событиях |
| среднее, n>~100·skew² | Уэлч | дефолт всегда |
| скошенные деньги + малые n | Манн–Уитни / permutation | MW проверяет P(X>Y), НЕ медианы |
| выбросы-киты | бутстрап юзерами / винзоризация (общий трешолд!) | винзоризация меняет эстиманд |
| до/после | парный t | это же идея CUPED |
| 3+ группы | ANOVA (= регрессия с dummy) | post-hoc с Холмом |
| ratio | дельта-метод / линеаризация | t по заказам НЕЛЬЗЯ |

## Красные флаги (остановиться и подумать)
- «продлили тест, прокрасилось» → peeking, α уже сломан (М3.7)
- p=0.049 против 0.051 → одна и та же сила доказательств, смотри CI эффекта
- статзначимость ≠ практическая значимость → всегда эффект + CI + перевод в деньги
