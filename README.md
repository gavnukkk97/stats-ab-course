# Проверка гипотез: статистика, АБ-тесты, каузальный вывод

Учебный курс для продуктовых аналитиков: от базовой статистики до каузального вывода, когда АБ-тест невозможен, и проектирования платформы экспериментирования. **Курс завершён.**

## Что здесь

```
course/
  plan.md            — детальный план: 7 модулей, 36 уроков, источники к каждому уроку
  content/M1..M7/    — уроки + практики + визуализации (92 схемы)
skills/              — 7 скиллов-шпаргалок + дорожная карта выбора метода
obsidian-vault/      — граф знаний: открыть в Obsidian (Open folder as vault)
```

> Конспекты внешних источников (книги, телеграм-каналы, статьи) хранятся у авторов локально и в репозиторий не выкладываются (авторские права); уроки ссылаются на них в разделах «Источники» как на локальную папку `materials/`.

## Модули

| # | Модуль | Статус |
|---|---|---|
| М1 | Базовая статистика (описательные, распределения, ЦПТ/CI, бутстрап) | ✅ 4 урока |
| М2 | Проверка гипотез (NHST, t-тесты, непараметрика, множественные сравнения, ANOVA) | ✅ 5 уроков |
| М3 | Статистика для АБ (MDE, юниты, ratio-метрики, винзоризация, CUPED/CUPAC, sequential) | ✅ 7 уроков |
| М4 | АБ на практике (цикл, сплит-система, SRM, кумулятивные эффекты и холдауты, AgentA/B) | ✅ 6 уроков |
| М5 | Байесовские методы (вывод, байесовский A/B, бандиты, иерархические модели/PyMC) | ✅ 5 уроков |
| М6 | Каузальный вывод (DAG, potential outcomes, DiD+PSM, RDD, IV, sensitivity) | ✅ 5 уроков |
| М7 | Проектирование АБ-платформы (сплит, данные, интерфейс, календарь гипотез) | ✅ 4 урока |

**Итого: 36 уроков, 35 практик (все запускаются exit 0 из чистого клона), 92 визуализации (v01–v92), 128 картинок в уроках, сквозной кейс «ЕдаДома».**

## Дорожная карта: как на практике выбирают метод

Если не знаете, с чего начать — начните отсюда. В реальной работе выбор метода оценки эффекта почти всегда выглядит так:

![Как на практике выбирают метод](skills/method-roadmap/assets/decision_roadmap.png)

Коротко: **сначала борются за A/B-тест** (90% кейсов) → нельзя рандомизировать → лестница вниз: DiD → RDD → synthetic control → PSM/IPW → IV → и честное «не делаем выводов». Каждый шаг вниз — новые допущения и обязательные проверки (плацебо, sensitivity).

## Скиллы (шпаргалки-навигаторы)

В папке `skills/` — 7 скиллов-шпаргалок, каждый закрывает типовую задачу (формат SKILL.md, читаются как обычный markdown):

| Скилл | Когда использовать |
|---|---|
| `method-roadmap` | точка входа: любой вопрос «измерить эффект» → сюда |
| `choose-stat-test` | «каким тестом проверить конверсию/чек/retention» |
| `design-ab-test` | планирование эксперимента: дизайн-док, MDE→n, guardrails |
| `analyze-ab-test` | подведение итогов: SRM-гейт → тесты → вердикт → отчёт |
| `bayesian-ab-test` | P(B>A), expected loss, когда остановиться, бандиты |
| `causal-estimation` | эффект без эксперимента: DiD/RDD/SC/PSM/IV + дерево выбора |
| `ab-platform-design` | устройство платформы: сплит, данные, гейты, календарь гипотез |

## Как пользоваться

- **Читать уроки**: `course/content/M1/lesson-1.1.md` и т.д. — markdown с формулами и встроенными картинками.
- **Obsidian**: открыть папку `obsidian-vault/` как хранилище (Open folder as vault) — граф знаний и копии уроков.
- **Практики**: `python3 course/content/M1/practice_1_1.py` — нужны `numpy scipy matplotlib pandas`. Все практики самодостаточны (синтетические данные с seed) и запускаются сверху вниз.

## Принципы курса

- **Сквозной кейс** «ЕдаДома» (доставка еды) — от описательных метрик до каузальных оценок.
- **Симуляционная культура**: не верь формуле — проверь симуляцией (в каждой практике).
- **Визуальный стандарт**: 3–4 поясняющие схемы на урок, заголовок = вывод.
