# Проверка гипотез: статистика, АБ-тесты, каузальный вывод

Учебный курс для продуктовых аналитиков: от базовой статистики до каузального вывода, когда АБ-тест невозможен. В разработке.

## Что здесь

```
course/
  plan.md            — детальный план: 6 модулей, 29 уроков, источники к каждому уроку
  content/M1/        — ✅ ГОТОВО: 4 урока + практики + 12 визуализаций
  content/M2/        — ✅ ГОТОВО: 5 уроков + практики + 19 визуализаций
  content/M3..M6/    — в очереди
materials/
  INDEX.md           — карта всех источников по модулям
  local/             — конспекты локальных курсов и книг (Кохави, karpov-симулятор, X5…)
  telegram/          — дайджесты 5 каналов по статистике/АБ + статьи
  web/               — конспекты веб-статей, research-подборки (чувствительность, arXiv, DiD+PSM)
  transcripts/       — транскрипты курса Глеба Михайлова
obsidian-vault/      — граф знаний: открыть в Obsidian (Open folder as vault)
```

## Модули

| # | Модуль | Статус |
|---|---|---|
| М1 | Базовая статистика (описательные, распределения, ЦПТ/CI, бутстрап) | ✅ 4 урока |
| М2 | Проверка гипотез (NHST, t-тесты, непараметрика, множественные сравнения, ANOVA) | ✅ 5 уроков |
| М3 | Статистика для АБ (MDE, юниты, ratio-метрики, винзоризация, CUPED/CUPAC, sequential) | ✅ 7 уроков |
| М4 | АБ на практике (цикл, сплит-система, SRM, кумулятивные эффекты и холдауты, AgentA/B) | ✅ 6 уроков |
| М5 | Байесовские методы (вывод, байесовский A/B, бандиты, иерархические модели/PyMC) | ✅ 5 уроков |
| М6 | Каузальный вывод (DAG, potential outcomes, DiD+PSM, RDD, IV, sensitivity) | ✅ 5 уроков |
| М7 | Проектирование АБ-платформы (сплит, данные, интерфейс, календарь гипотез) | ✅ 4 урока |
**Итого: 36 уроков, 35 практик (все запускаются exit 0 из чистого клона), 92 визуализации (v01–v92), 128 картинок в уроках, сквозной кейс «ЕдаДома».**

## Как пользоваться

- **Читать уроки**: `course/content/M1/lesson-1.1.md` и т.д. — markdown с формулами и встроенными картинками.
- **Obsidian**: открыть папку `obsidian-vault/` как хранилище (Open folder as vault) — там граф знаний по всем материалам и копии уроков.
- **Практики**: `python3 course/content/M1/practice_1_1.py` — нужны `numpy scipy matplotlib pandas`. Все практики самодостаточны (синтетические данные с seed) и запускаются сверху вниз.

## Принципы курса

- **Сквозной кейс** «ЕдаДома» (доставка еды) — от описательных метрик до каузальных оценок.
- **Симуляционная культура**: не верь формуле — проверь симуляцией (в каждой практике).
- **Визуальный стандарт**: 3–4 поясняющие схемы на урок, заголовок = вывод.

## ⚠️ Важно про материалы

`materials/` содержит конспекты и цитаты внешних источников (книги, платные курсы, телеграм-каналы). Репозиторий **приватный**, только для внутреннего использования; не публиковать и не распространять за пределами команды.
