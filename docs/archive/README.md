В `prompts/M3/` и `prompts/M6/` сохранены прежние задания для подготовки уроков. Это история авторской работы: пути, формулировки и требования в этих файлах могут не соответствовать текущему курсу.

Действующие инструкции — в [руководстве для авторов](../DEVELOPMENT.md), учебные материалы — в [модулях курса](../../course/modules/README.md).
