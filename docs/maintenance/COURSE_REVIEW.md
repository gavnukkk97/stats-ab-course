## Как читать список

- **P1** — исправить до обучения по соответствующему материалу: ошибка может менять проверяемую гипотезу, статистический вывод или решение о раскатке.
- **P2** — существенная неточность, отсутствующее допущение, противоречие либо методическая доработка.
- **P3** — локальная редактура, ясность или навигация.
- Рекомендации по педагогике и утверждения, которым недостаёт источника, обозначены отдельно от доказанных вычислительных ошибок. Один пункт может объединять несколько связанных мест; сквозные проблемы встречаются в нескольких разделах и не являются независимыми дефектами каждый раз.
- Ссылки ведут к файлам и первым строкам соответствующих фрагментов. Номера строк относятся к состоянию репозитория во время аудита. Для одинаковых копий в Obsidian обычно дана ссылка на основной файл курса.

## С чего начать

1. **Исправить правила решений:** отрицательный эффект приводит к ROLL; остановка по инварианту не блокирует SHIP; ROPE не распознаёт вред. См. P01, T04, I06.
2. **Исправить базовые иллюстрации:** перепутанные α/β, неверные p-value монеты, неправильные перестановки, пороги Холма ×20, A/A с разными истинными средними. См. B01–B05.
3. **Пересчитать планирование:** неверная кривая мощности, потерянный множитель 2 в общем N, выборка expected loss занижена примерно в 7,2 раза. См. I02, I05, T01.
4. **Согласовать определения:** p-value, α/FWER/FDR, MDE и бизнес-порог, отсутствие значимости и отсутствие эффекта. См. B07–B12, I13, I27, K08–K11.
5. **Исправить выбор популяции и метрики:** ITT/exposure, анализ по кликерам, поздние заказы, ratio, преобразованный p-value для сырого эффекта. См. P03, P08, I08–I10, K08.
6. **Закрыть утечку в CUPAC и рассогласования CUPED/ANCOVA/Lin.** См. I03, I14–I17.
7. **Исправить байесовские гарантии и бандиты:** EL не даёт заявленной частотной гарантии; скользящее окно Thompson считает неверные posterior. См. I01, I04–I07.
8. **Переписать каузальные рекомендации:** убрать выдуманные уровни доверия и интервалы, исправить sensitivity, matching/DiD inference и рисунки. См. C01–C14.
9. **Пересчитать экономику:** единицы эффекта, счётчик вредных релизов, знаменатель конверсии, маргинальные эффекты, горизонт и вероятности потерь. См. P05–P06, P12, P16–P20.
10. **Исправить кейсы, которые учат делать вывод без данных:** красная кнопка, Spotify, 3D-модели, eBay, Snapchat. См. K01, K04–K05, K08–K11, K26–K29.
11. **Сделать воспроизводимую сборку:** зависимости, единые вычисления для текста и рисунков, проверки свойств симуляций, синхронизация зеркала. См. S08–S10.
12. **Перестроить обучение вокруг компетенций:** вводный полный цикл, корректный самотест, зависимости тем, самостоятельные задания и итоговый проект. См. S01–S07.

Не нужно сразу добавлять больше продвинутых тем: сначала исправить базовый путь, по которому ученик учится выбирать метрику, строить эксперимент и принимать решение.

## Критерии готовности исправленного курса

1. Для каждого P1 есть исправленный текст/код/рисунок и небольшой воспроизводимый пример, подтверждающий правильный ответ; исправления синхронизированы с конспектами и skills.

4. В каждом уроке ясны вопрос, estimand, предположения, метод, ограничения и то, что ученик должен уметь сделать самостоятельно.
5. Несколько учащихся целевой аудитории проходят основной маршрут без подсказок автора; по их ошибкам уточняются объяснения, задания и оценка времени.
