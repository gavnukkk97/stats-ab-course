# Архив вспомогательных скриптов

`transcribe_gm.py` — прежний инструмент расшифровки локальных материалов. Он использует пути к исходным записям на компьютере автора, `afconvert` и `faster-whisper`; эти материалы и зависимости не входят в курс. Скрипт сохранён как история подготовки, не участвует в запуске практик и проверках курса.

Актуальные команды — в [руководстве для авторов](../../docs/DEVELOPMENT.md).
