# M5. Байесовские методы

Связывать априорные предположения, данные, неопределённость и потери при принятии решения.

Специализация после основного маршрута M1–M4. Для практики 5.5 нужны [дополнительные зависимости](../../../requirements/bayes.txt).

## Как работать с модулем

Тексты уроков лежат в этой папке. В `practice/` находятся готовые исполняемые разборы, в `images/` — все рисунки модуля. Самостоятельные задания собраны в [общей тетради](../../exercises/README.md).

Прочитайте урок, попробуйте решить задание до просмотра готового кода, затем запустите разбор и объясните полученный результат. [Как настроить Python](../../../README.md#запустить-первую-практику).
