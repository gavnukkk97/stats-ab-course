# Модули курса

Начните с [одного полного эксперимента](../START_HERE.md), затем выберите [маршрут обучения](../NAVIGATION.md) по своей подготовке. Основное ядро проходит через M1–M4; M5–M7 — специализации.

У каждого модуля есть оглавление со ссылками на уроки, готовые разборы и самостоятельные задания. Рисунки находятся в `images/`, готовый код — в `practice/`, заготовки M1/M2 — в `exercises/`.

| Модуль | Результат обучения | Уроков |
|---|---|---:|
| [M1. Базовая статистика](M1/README.md) | Описывать данные, различать распределения и объяснять неопределённость оценки. | 4 |
| [M2. Проверка гипотез](M2/README.md) | Выбирать проверку под задачу и дизайн данных, понимать p-value и учитывать множественность. | 5 |
| [M3. Статистика для А/Б](M3/README.md) | Планировать размер эксперимента, выбирать единицу анализа и оценивать эффект с учётом особенностей метрики. | 7 |
| [M4. А/Б на практике](M4/README.md) | Пройти путь от гипотезы и протокола до проверки качества данных и решения о запуске изменения. | 6 |
| [M5. Байесовские методы](M5/README.md) | Связывать априорные предположения, данные, неопределённость и потери при принятии решения. | 5 |
| [M6. Причинный вывод](M6/README.md) | Формулировать причинный вопрос и выбирать метод с явными допущениями, когда обычный А/Б-тест недоступен. | 5 |
| [M7. Платформа экспериментов](M7/README.md) | Связать назначение вариантов, сбор данных, проверки и правила решений в воспроизводимый процесс. | 4 |

После основного маршрута выполните [итоговый проект](../capstone/README.md). Дополнительные задачи — в [библиотеке кейсов](../cases/README.md).
