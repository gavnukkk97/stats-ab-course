# Зависимости тем

Пропускать тему можно после проверки её компетенций, а не потому, что сюжет примера относится к другой отрасли.

| Уроки | Что знать до них |
|---|---|
| 1.1–1.2 | доли, средние, базовая вероятность; Python для практики |
| 1.3–1.4 | распределения, mean/variance, повторные выборки |
| 2.1–2.2 | CI, SE, нормальное и t-распределения |
| 2.3 | постановка H0/H1, estimand, обменяемость, парность |
| 2.4–2.5 | p-value, α, семейство решений; для ANOVA — разложение вариации |
| 3.1 | α, power, SE; отдельно бизнес-порог |
| 3.2 | зависимость наблюдений и механизм назначения |
| 3.3 | covariance, агрегация на пользователе; основы delta method |
| 3.4–3.5 | estimand, SE, covariance; для CUPED — линейная регрессия |
| 3.6 | CUPED, OLS, robust SE, cross-fitting |
| 3.7 | фиксированный тест, семейство просмотров; для вывода mSPRT — likelihood |
| 4.1–4.2 | весь базовый цикл, MDE и рандомизация |
| 4.3–4.5 | единицы, качество данных, CI, guardrails и правило решения |
| 4.6 | внутренняя и внешняя валидность, отличие модели от живой популяции |
| 5.1–5.3 | условная вероятность, prior/likelihood, loss function |
| 5.4 | posterior updates, exploration и горизонт решения |
| 5.5 | иерархии, регрессия, MCMC, posterior predictive checks |
| 6.1–6.2 | условная независимость, потенциальные исходы, estimand |
| 6.3 | регрессия, панельные/кластерные данные; разбить занятие по дизайнам |
| 6.4 | regression adjustment, overlap, условные ожидания; отдельное занятие на каждый оценщик |
| 6.5 | идентифицирующие допущения выбранного дизайна, интерпретация CI |
| 7.1–7.4 | M3/M4; Python, данные событий, версии конфигурации и стоимость вычислений |
