# Обозначения и язык курса

| Термин | Значение и правило записи |
|---|---|
| A / B | Контроль / тест; эффект по умолчанию B−A. Для метрики «меньше лучше» направление пользы задаём отдельно. |
| Проценты и процентные пункты | Рост конверсии с 10% до 12%: +2 п.п. или +20% относительно контроля. Всегда указываем шкалу. |
| n_A, n_B; N | Число независимых единиц в каждой группе; N=n_A+n_B — общий размер. Число строк событий не равно числу независимых единиц. |
| SD, σ | Разброс отдельных наблюдений. Размер выборки пропорционален дисперсии σ² при прочих равных. |
| SE | Неопределённость оценки. Для среднего независимых одинаково распределённых наблюдений SE≈SD/√n; для разности, ratio и кластеров нужна соответствующая формула. |
| Estimand | Какой эффект хотим оценить: исход, популяция, период, сравниваемые воздействия и способ усреднения. |
| Оценка / estimator | Число по данным / процедура, которая его получает. Разные процедуры могут оценивать одну цель; mean и median обычно имеют разные цели. |
| α / p-value | Предзаданный уровень ошибки I рода / вероятность результата не менее экстремального при H0 и принятой модели. p не является P(H0\|данные). |
| Мощность 1−β | Вероятность отвергнуть H0 при конкретном альтернативном эффекте и дизайне. Не вероятность «гипотеза верна». |
| MDE | Эффект, при котором дизайн имеет заданную мощность. Эффекты меньше MDE могут быть обнаружены. |
| Бизнес-порог | Минимальная полезная величина эффекта с учётом затрат. Проверка отличия от 0 и подтверждение превышения этого порога — разные задачи. |
| CI | Доверительный интервал: покрытие относится к процедуре при повторных данных. 95% CI не означает 95% наблюдений внутри него. |
| CrI / HDI | Байесовский правдоподобный интервал / интервал высокой posterior-плотности, условные на данных, likelihood и prior. Не называем их частотным CI. |
| Априорное распределение (prior) | Модель параметра до текущих данных; posterior — после обновления. Проводим анализ чувствительности к существенным предположениям. |
| Assignment / exposure | Назначение варианта / фактический контакт с ним. Это разные события. |
| ITT | Эффект назначения среди всей заранее определённой eligible-популяции, включая не вступивших в контакт. Отбор по последствиям воздействия меняет эту цель. |
| OEC | Основная метрика решения, связанная с бизнес-целью. Диагностический CTR не становится метрикой ценности только из-за высокой чувствительности. |
| Guardrail | Защитная метрика с направлением вреда и допустимой границей. «Вред не обнаружен» и «неприемлемый вред исключён» — разные выводы. |
| Инвариант / диагностика логов | Характеристика, которую воздействие по дизайну не должно менять / проверка полноты и корректности данных. Продуктовые outcomes нельзя автоматически считать инвариантами. |
| SRM | Несовместимость наблюдаемого распределения назначений с запланированными долями; сигнал для расследования, не название причины. |
| Точный результат / приближение / эвристика | Различаем доказанное при указанных условиях, асимптотическое приближение и практическое правило. У симуляционной частоты указываем число миров и Monte Carlo погрешность. |

В вычислениях деньги храним в обозначенных единицах (рубли или копейки), вероятности — долями 0…1; форматирование в проценты не меняет расчётную шкалу. В готовом отчёте расшифровываем незнакомые сокращения при первом появлении.
